## 📌 Project Overview
This project uses **Machine Learning (K-Means Clustering)** to segment fintech customers based on their financial and transaction behavior.

The goal is to identify different customer groups and provide insights that can help fintech companies create **personalized marketing, financial products, and customer strategies**.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means Clustering
- PCA

## 🔍 Methodology
- Exploratory Data Analysis (EDA)
- Feature Scaling using StandardScaler
- K-Means Clustering
- Elbow Method
- Silhouette Score
- PCA for 2D visualization
- Customer segment profiling

## 📊 Key Outcome
Customers were grouped into different segments based on their income, spending, credit score, transactions, investments, and savings.

These segments can help fintech companies develop **targeted offers and personalized financial services**.

## 🎯 Business Applications
- Customer targeting
- Personalized offers
- Investment recommendations
- Credit/loan marketing
- Customer retention strategies
